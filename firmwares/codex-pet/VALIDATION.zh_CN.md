# 验证 — 2026-09-09，版本 0.6.0

## Build

PASS：`.venv/bin/python scripts/firmware.py build codex-pet` 与 `build codex`。Pet 应用大小 2,181,200 / 3,145,728 字节；合并镜像 2,246,736 字节。原 Codex 消费者默认仍只接受类型 1–2，Pet 显式启用等待类型 3。Rust Release 构建与 Clippy `-D warnings` 通过。

Pet 合并镜像 SHA-256：`86431e5526eb92f21e7626eb78cecc721a0410b488aee5960553bf50c9cae5fc`。受保护的仅应用安装在写入前后核验原始引导程序、分区表与卡身份。板级源文件、音频时钟及通道配置未变。

## Host tests

PASS：29 项 Rust 测试，覆盖等待状态识别、每次进入等待仅提醒一次、解决后取消待发提醒、与完成事件共存、拒绝连接前的延迟快照、重连基线，以及旧固件能力降级。

PASS：Pet 主机门禁。4,287 帧 C 动画与 Python zlib 一致（CRC `01db9af3`）；21 个序列边界，以及原有渲染、行为、电源和通知超时测试通过。84,902 个音频采样与源 WAV 哈希和生成 PCM 一致。成功／失败／等待分别包含 35,945／36,000／12,957 个采样，峰值受限且端点为零。PCM 占用 169,804 字节 Flash，经 512 字节栈缓冲区分块播放，不使用实时合成或整段音频 RAM 分配。

## Device tests

PASS：`tools/device_test.py --audio-timing --expiry --perf --seconds 6 --output reports/pet-v60-device.json`。

- 音频输出工作任务耗时：成功 2.196 秒、失败 2.199 秒、等待 0.761 秒。源时长为 2.247／2.250／0.810 秒；任务完成后 DMA 继续排空尾部。这不是声学时长测量。
- 等待类型 3 可接收，显示 `WAITING`，重复包不会再次响铃或增加未读快照。已目视检查渲染截图 `reports/pet-v60-waiting.png`。
- 15 秒超时、信息页暂停计时、重复包不重置计时、恢复旧快照及 OK 关闭均通过。
- 六个序列的软件性能窗口为 59.3–59.7 FPS。测试结束后未读为零；生产 USB 同步已恢复，固件 0.6.0 兼容，本机与 devbox 来源均健康。

证据（忽略文件）：`reports/pet-v60-device.json`、`reports/pet-v60-service.json` 与等待截图。源 WAV 和来源记录保存在 `assets/sounds/`。

## 限制与 Unverified

本机等待检测为**不可用**，不是验证通过：本机桌面 App Server 使用 stdio，没有可复用的控制 socket。本机完成／停止检测仍可工作。远端授权／回答等待检测已按明确的 App Server 标志实现并通过主机夹具测试；本轮没有主动制造真实用户授权／回答交互。设备类型 3 音效通过真实 USB 协议测试。

本轮未测量实际声学音高／音色和扬声器声压、BLE、光学扫描平滑度、物理按键／背光、连续一小时真实闲置及长期稳定性。此前快速 BLE 半帧断线重连压力测试失败仍未解决。历史电源／页脚测试见此前变更记录，本轮未全部复跑。设备通知仍仅保存在 RAM。
