# 使用指南

## 连接与管理

打开 `macos-app/build/Passport.app`。Passport 只显示在菜单栏，打开后启动 Rust 后台。可用的 USB 数据连接优先，否则自动连接已配对的 BLE。保持 Mac 唤醒、设备开机，无需 Wi-Fi。

菜单分别展示服务状态、USB/BLE 连接、固件兼容性及本机／SSH 采集源状态。未知、不兼容或旧固件不会收到 Codex 业务数据；当前固件已支持 Passport 身份查询。

| 菜单操作 | 效果 |
| --- | --- |
| 启动服务 | 开始采集并自动连接设备 |
| 停止服务 | 停止采集、释放设备、关闭所属 SSH 子进程，保留菜单栏 |
| 重启服务 | 等旧实例退出后启动 |
| 重新连接设备 | 只重建设备连接，保留待发送提醒 |
| 登录时启动 | 独立设置菜单栏应用的登录启动 |
| 退出 Passport | 先停止后台，再退出菜单栏 |

停止服务不改变登录启动设置。重新打开应用会启动服务，关闭终端没有影响。菜单栏崩溃后，后台在控制连接失联十秒后清理退出；后台连续崩溃每分钟最多自动重试三次。停止超过 40 秒会报告错误，并提供明确的强制停止操作。

```bash
cd /Users/bytedance/KProjects/traetoy
./scripts/bridge-service.sh start
./scripts/bridge-service.sh status
./scripts/bridge-service.sh stop
./scripts/bridge-service.sh restart
./scripts/bridge-service.sh reconnect
./scripts/bridge-service.sh quit
```

命令行与菜单共享控制逻辑；`status` 返回应用、后台、设备和采集源的结构化状态。launchd 仅在 Passport 请求运行时托管 Rust，配置仍为 `~/Library/LaunchAgents/cn.folotoy.codex-passport.bridge.plist`，无需 sudo。若 macOS 要求批准登录启动，请前往系统设置 → 通用 → 登录项。

## 屏幕与按键

- 额度表盘：剩余额度百分比；`Resets in` 是重置倒计时，小于 24 小时时保留分钟。
- `Reset cards`：可用重置卡数量，只读显示，不会触发兑换。
- 七行用量：日期从新到旧，统一橙色条形和 token 数值；K／M／B 分别为千／百万／十亿。没有周汇总行。
- 七天窗口结束于接口最新报告的日期，因此可能不包含今天。缺失显示 `--`，确认用量为零才显示 `0`；它不是订阅剩余额度或账单金额。
- 底部：运行中的任务数量。任务页显示标题、项目／工作区及当前轮次耗时，时间不含秒数。

| 操作 | 行为 |
| --- | --- |
| 首页短按 OK | 有未读提醒先打开提醒，否则进入运行任务列表 |
| 息屏时按任意功能键 | 仅唤醒不导航；新提醒也会自动亮屏 |
| 任务页按上／下 | 切换任务／翻页 |
| 长按 OK | 返回首页；提醒页长按不会确认提醒 |
| 提醒页短按 OK | 确认当前提醒并显示下一条 |

提醒最新优先，最多保留八条，超出淘汰最旧一条。每条累计可见 30 秒后自动确认；被新提醒遮住或返回首页时暂停计时。清空后返回原页面。设备重启会清空内存中的未读提醒。每次任务响应轮次完成可触发提示，并非整个多轮会话结束才提醒。

无按键或新提醒 60 秒后，背光占空比由 75% 降至 35%，监控继续运行；按键或新提醒立即恢复 75%。这不是人眼感知亮度的线性百分比。

连续一小时无新通知时自动息屏，普通数据刷新或亮屏导航不延长计时。新通知自动亮屏并提示；手动唤醒重新计时一小时。息屏期间监控继续，提醒可见计时和画面重绘暂停。

## 更新频率与数据来源

| 信息 | 周期／来源 |
| --- | --- |
| 设备状态、运行时长 | 约 3 秒 |
| 远端任务发现 | 约 10 秒；活跃任务约 3 秒检查 |
| 额度、重置卡 | 约 60 秒，同一次请求 |
| token 用量 | 约 5 分钟，接口数据本身可能延迟 |
| 电池 | 约 30 秒 |

本地任务从本机 Codex 生命周期记录读取；远端任务及账号数据通过已配置的 SSH 别名访问现有 App Server。当前账号来源由 `config/bridge.json` 的 `account_host` 指定。云端任务不在当前监控范围内。SSH 断开会影响远端任务和账号数据，即使设备连接正常也可能显示缺失或过期。

## 排查

先查看服务状态，再查看最近日志：

```bash
./scripts/bridge-service.sh status
tail -n 30 reports/bridge.log
```

- 服务停止：运行 `start`；不要同时直接启动第二个 Rust 进程。
- 设备没更新：唤醒设备，确认 USB 数据线或蓝牙；必要时 `restart`。新 `CDX_ACK` 表示设备收到了数据，不表示用户已读提醒。
- BLE 超时：确认设备开机、在附近，Mac 蓝牙开启；在“系统设置 → 隐私与安全性 → 蓝牙”检查对应程序权限。单纯重启不需要重新配对。
- 远端不可用：在终端检查 `ssh devbox`（其他配置请替换别名），处理认证／网络问题后服务会重试。不要把 SSH 私钥写进启动配置。
- 额度或用量显示 `--`：可能是接口未返回、SSH 中断、数据过期或账号核验失败；这不等同于额度为零。更换账号后按开发文档重新核验。
- 工作区移动：先退出 Passport，在新路径重新构建应用并运行 `./scripts/bridge-service.sh install`；必要时重新启用登录项。

日志会按 2 MB 轮转，保留三份备份。日志可能含任务标题和路径，分享前需脱敏。

首次配对、开发构建、固件升级及资源测量见[开发指南](development.zh_CN.md)。

## 重置卡与连接页

首页上／下键循环切换「概览 → 重置卡 → 连接」。概览的 OK 仍优先打开未读提醒，没有提醒时进入运行任务列表。长按 OK 从任意页面回到概览。

重置卡概览显示可用数量与最近到期时间。按 OK 进入列表，上／下选择，OK 查看单张详情；详情中上／下滚动，短按 OK 返回列表。详情包含名称、状态、发放／过期时间、时区、类型和说明，不支持兑换。日期使用 Mac 的本地时区；`--` 表示接口未提供日期，不代表永久有效。

连接页分别显示当前 USB／BLE 接口、设备数据到达时间、本机与远端数据源健康状态、账号同步时间。数据源中断不会被误报为任务完成。设备断线时，来源状态标为缓存。新提醒会暂时覆盖功能页，确认完后返回原页。

当前最多显示六张卡和四个数据源。卡片按到期时间排序，超过显示上限时显示已载入数量／可用总数；接口有时只提供数量，详情页会显示暂无详情。较长名称或说明带省略号。新增页面复用现有请求，不增加采集频率。
