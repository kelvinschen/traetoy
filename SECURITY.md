# Security policy

Do not report unpatched vulnerabilities, credentials, private keys, device
identities, or exploitable details in public issues, pull requests, or
discussions.

## Reporting

Use GitHub private vulnerability reporting when it is enabled for this
repository. If it is unavailable, open a public issue that requests a private
contact channel only; do not include reproduction details there.

Include the affected commit, component, supported hardware, sanitized
reproduction steps, impact, and suggested mitigation. Maintainers target an
acknowledgement within five business days and coordinated disclosure within
ninety days when practical.

## Supported code

The current main branch is the supported source baseline. No binary release is
provided by this repository's initial public release.
