# Support

Read README.md, the development guide, and the hooks guide before opening an
issue. Use feature and usage issue forms for ordinary questions.

For security vulnerabilities, follow SECURITY.md. Do not include private
configuration, device identifiers, credentials, or unsanitized logs in any
support request.

Traetoy is community-maintained source software. Hardware warranty, official
FoloToy product support, and OpenAI account support are outside this project.
